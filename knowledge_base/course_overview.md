## 1. Course Description
CS 401 provides an intensive, practical exploration of modern artificial intelligence and applied machine learning systems. The curriculum bridges the gap between deep learning theory and production deployment, focusing on large language models (LLMs), retrieval-augmented generation (RAG), agentic workflows, vector search architectures, and AI application safety.

## 2. Prerequisites
Students must have completed:
- **CS 201: Data Structures & Algorithms** with a minimum grade of **B (3.0 GPA)**.
- **MATH 215: Linear Algebra and Probability** with a minimum grade of **C+ (2.3 GPA)**.
- Proficiency in Python 3.10+, object-oriented programming, and basic Linux command-line tools.

## 3. Course Modules and Topics
The semester is structured into five distinct academic modules over 15 weeks:

* **Module 1: Foundations of Machine Learning & Embeddings (Weeks 1–3)**
  - Dense representations, cosine similarity, distance metrics.
  - Sentence transformers, tokenization, and dimensional vector representations.
  - Practical lab: Building semantic search with ChromaDB and FAISS.

* **Module 2: Retrieval-Augmented Generation (RAG) Architecture (Weeks 4–6)**
  - Document parsing, text chunking strategies, chunk overlap calculations.
  - Vector indexing, semantic similarity matching, and hybrid retrieval.
  - Grounding techniques, prompt template construction, source attribution, and hallucination reduction.

* **Module 3: Autonomous Agents & Graph Workflows (Weeks 7–9)**
  - State machines, LangGraph orchestration, multi-turn state propagation.
  - Tool calling, router nodes, conditional branches, and cyclic agent architectures.
  - Execution limits, recursion controls, and deterministic path execution.

* **Module 4: Conversation Memory & Context Management (Weeks 10–12)**
  - Chat history tracking, session management, and sliding window buffers.
  - Question rewriting chains, contextual disambiguation, and coreference resolution.
  - Token budget management and memory summarization.

* **Module 5: AI Safety, Evaluation & Production Deployment (Weeks 13–15)**
  - Prompt injection prevention, input sanitization, and safety boundaries.
  - Automated evaluation benchmarks, routing accuracy, and ground truth validation.
  - Packaging Streamlit web apps and cloud container deployment.
